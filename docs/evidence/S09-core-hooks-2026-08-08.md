## G2：解释与独立设计

`LifecycleDispatcher` 继续 observation-only；`HookCoordinator` 独立负责有界匹配、并发执行、
稳定聚合、超时/取消和失败策略。Hook 输入只包含已脱敏摘要；Pre Tool 不能绕过 Permission，
Post Tool 不能撤销副作用。

## G3：实现

- Domain：Hook Event、Matcher、Invocation、Execution Result、Aggregate Result；
- Core：Hook Handler Port、Binding、Coordinator；
- Tool Pipeline：参数校验后执行 Pre Tool，ASK 前执行 Permission Hook，规范 Result/生命周期记录后执行 Post Tool；
- Session/Runtime：InMemory/File Session Start/End、User Prompt、Run、Model Turn 生命周期接入；
- CLI：固定 argv、空环境和 JSON stdin/stdout 的 `CommandHookHandler`，支持超时、取消、输出上限和进程树清理；
- Trust：ADR-054 提供来源枚举、长度前缀 SHA-256 指纹和项目来源显式 Workspace/批准 Gate；
- Hook 阻断映射为带原始 Call ID 的结构化 `HOOK_BLOCKED` Tool Error。
