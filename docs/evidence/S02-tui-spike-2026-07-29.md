## 要证伪的问题

React/Ink 能否作为 Java Runtime 之外的纯终端 Surface，通过内部 stdio v0 提供中文输入、
流式文本、取消、非 TTY 降级和确定性进程清理，同时不把 Agent 决策移入 Node。

## 独立实现

- `StdioClient` 使用 `spawn(executable, args)`，不经过 Shell 字符串；
- stdout 按 64 KiB 有界字节行读取，使用 fatal UTF-8 解码并验证事件 sequence；
- stderr 始终排空但不显示原文，只保留字节计数；
- `reduceTuiState` 是纯 Reducer，只有 Java 终态能完成或取消 Run；
- `AgentTui` 处理 Backspace、中文输入、`usePaste`、`useWindowSize` 和 `Ctrl+C`；
- 非 TTY 路径只输出纯文本，不产生 ANSI；
- Windows Demo Script 先编译测试专用 Java Fixture，再以 Base64 包装的结构化参数拉起，
  不让 Classpath 经过 Shell 拼接。

## 验证结果

### TypeScript 与离线测试

```text
cd cc-java-tui
npm.cmd run check
```

结果：TypeScript 严格编译通过；5 个 Test File、12/12 Test 通过。

覆盖：

- 连续/乱序/缺字段协议事件；
- Delta 聚合、唯一 Java 终态投影和错误文案脱敏；
- 结构化 Fake 子进程、流式输出、取消、乱序后终止；
- 中文宽字符、20 列窄布局、Backspace Unicode 删除和中断决策；
- 非 TTY 纯文本输出且不含 ANSI。

### Java/Node 非 TTY 跨语言 Demo

```text
powershell.exe -NoProfile -ExecutionPolicy Bypass -File `
  .\scripts\RunS02TuiSpike.ps1 -Prompt "hello"
```

实际输出：

```text
alpha beta
```

退出码为 0。

### Windows TTY 手工观察

实际启动后输入 `你好`：

```text
状态：running
> 你好
alpha beta
[completed]
状态：ready
```

空闲 `Ctrl+C` 显示 `closing`，Java 与 Node 进程均正常退出，退出码为 0。
活动 Run 的取消命令由离线真实子进程测试覆盖；本次手工终端输入未形成可重放的
Resize/Bracketed Paste 记录，因此不把它们声明为已完成 G5。
