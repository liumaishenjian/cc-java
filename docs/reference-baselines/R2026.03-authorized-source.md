## 6. S07 Context 机制基线

本节逐项区分直接观察、综合推断和本项目设计。完整采纳理由见
[ADR-019](../adr/ADR-019-s07-progressive-context-reduction.md)。

### 6.1 机制结论

| 结论 | 分类 |
| --- | --- |
| 存在单批 Tool Payload 限流、外置或占位路径 | `Observed` |
| 存在选择性清理旧 Tool Result、保留近期工作集的路径 | `Observed` |
| 存在 Rolling Session Memory、覆盖边界和近期完整尾部 | `Observed` |
| 存在 Full Conversation Summary 和 Overflow 恢复路径 | `Observed` |
| 手动 Compact 与自动触发具有不同入口 | `Observed` |
| 多种减压机制可综合为渐进式条件决策图 | `Inferred` |
| “四级能力”适合作为 Java 学习切片 | `Inferred` |
| Canonical Transcript 与 Model Context Projection 应作为独立契约 | `Inferred` |

“渐进式 Context Reduction 决策图”和以下“四级能力”是本项目的 `Inferred` 综合，
不是已确认的上游正式术语，也不是每个请求固定执行四次压缩：

1. 单批 Tool Payload 限流、必要时外置并保持稳定占位；
2. 选择性清理旧 Tool Result，保留最近工作集和 Call ID；
3. Rolling Session Memory，加协议安全的近期完整尾部；
4. Full Conversation Summary，以及 Context Overflow 后的一次有界恢复。

### 6.2 采纳时使用的结论

| 结论 | 分类 |
| --- | --- |
| 只按完整 Protocol Round 淘汰，避免孤立 Tool Call/Result | `Inferred` |
| 记忆覆盖位置只在无悬空 Tool Call 的安全边界推进 | `Inferred` |
| 记忆缺失、为空、过期、边界无效或结果仍超阈值时回退 Full Summary | `Inferred` |
| 摘要失败、取消或空结果不能提交 Compaction Boundary | `Observed` |
| 同一次 Overflow 最多进行一次 compact-and-retry，再失败明确停止 | `Observed` |
| 手动 Compact 与自动路径共享协议和提交不变量 | `Inferred` |
| 压缩后需要恢复有效 Instructions、文件、计划和未完成任务状态 | `Inferred` |
| Usage 应按最终 Model Context Projection 重新计算 | `Inferred` |

Provider Context Editing 只进入 Adapter、`ContextPreparationService` 的具体契约等内容属于
`cc-java Design`，不是参考事实，统一由 ADR-019 和技术设计解释。

当前快照引用了未包含的增量折叠和反应式压缩实现。相关算法细节保持 `Unknown`，
不得凭调用名称补写。
