# R2026.03 公开行为基线

- Baseline ID: `R2026.03`
- Status: Provisional Scope Baseline
- Registered: 2026-07-28
- Manifest Stability: 本文列出的来源 ID、URL 和用途在本 Baseline 内固定
- Content Reproducibility: 当前在线页面未归档、未保存内容指纹，历史页面内容不可字节复现
- Behavior Capture: 尚未形成可重放的参考产品黑盒观察包

`R2026.03` 是第一轮学习范围的标识，不是“所有链接内容都冻结在 2026 年 3 月”的声明。
名称中的 `2026.03` 来源于 `REF-01` 对其研究对象时间的自述；它不能证明其他页面在该月
的内容，也不能证明任何未核验本地材料与该时间点的正式产品版本一致。

## 1. 用途

本基线回答“哪些公开行为值得独立验收”。它与
[授权参考源码登记](./R2026.03-authorized-source.md)的边界如下：

- 公开官方文档和独立黑盒场景定义候选行为需求；
- 第三方分析只提供研究问题和机制假设，不能单独成为行为 Oracle；
- 授权源码只帮助解释机制，不自动定义公开行为或充当测试 Oracle；
- `cc-java` 自己的测试、Demo 和 Eval 才能证明实现等级。

S01 的 L1 只代表本项目离线学习骨架已经通过独立协议测试。当前没有参考产品黑盒观察包，
因此不能依据本基线宣称 S01 已达到 L3 或完成参考行为对照。

## 3. 结论等级

公开材料同样使用结论标签：

| 标记 | 含义 |
| --- | --- |
| `Documented` | 当前 Stage 研究记录在访问当日从官方文档确认的公开说明 |
| `Observed` | 通过独立黑盒场景直接观察到的输入、事件、副作用或终态 |
| `Inferred` | 来自二手材料、跨材料综合或对机制的解释 |
| `Unknown` | 页面版本、产品版本、环境或行为无法确认 |
| `Verified in cc-java` | 本项目独立实现已通过测试、Demo 或 Eval |

`Documented` 不等于 `Observed`，`Observed` 也不等于 `Verified in cc-java`。

## 4. Stage 使用规则

每个实际引用公开资料的 Stage 证据包必须记录：

1. 来源 ID、URL、访问日期和页面标题或小节；
2. 用自己的语言写出的最小行为说明；
3. `Documented / Observed / Inferred / Unknown`；
4. 产品版本、环境、输入和可观察结果；无法确认时明确写 `Unknown`；
5. 独立编写的正例、负例和失败场景；
6. 与授权机制研究、本项目独立设计和本项目验证结果的边界。

达到 L1/L2 可以使用独立需求和本项目测试作为证据。若要达到 L3，必须另外持久记录
可复现的参考行为观察或有版本依据的官方行为声明，并说明页面或产品漂移如何处理。

## 5. 升级 Baseline

以下任一情况发生时新建 Baseline，而不是静默修改 `R2026.03` 的语义：

- 参考产品行为发生影响验收的变化；
- 获得带版本号或可归档的官方文档；
- 形成首个可重放的黑盒观察包；
- 新增或移除会改变 Capability Matrix 范围的来源；
- 参考框架版本变化影响 Java Adapter 契约。

升级记录至少包含新增、删除、行为变化、受影响 Feature ID 和回归结果。
