# S10 MCP 差距报告

更新时间：2026-08-09

## 已完成

- STDIO 与 Streamable HTTP、多 Server、Tool 映射、filter、前缀、Permission、Trust 和单次断线恢复；
- 真实两个 Transport E2E 与完整 Headless Agent Loop E2E；
- MCP SDK 隔离在 Adapter，所有 MCP Tool 经统一 Tool Registry/Permission/Approval/Pipeline；
- Resource/Prompt 有界元数据发现，Bearer Token 从环境读取且不进入诊断。

## 仍然缺失

1. `MCP-08` Lazy Tool Loading / Tool Search 仍为 L0，Server Tool Schema 当前在启动时发现；
2. `MCP-09` 只到元数据目录，尚无 Resource read、Prompt get、用户选择和 Context Projection；
3. `MCP-10` 只有环境 Bearer，没有 OAuth、动态注册、token cache/refresh；
4. `MCP-11` 有来源指纹、状态与显式 project trust，但没有逐 Server 风险详情或组织 Managed Policy；
5. 没有 S13 OS 网络 Sandbox，也没有 S14 稳定外部配置/机器协议和跨版本迁移保证。

## 后续顺序

S11 可复用 Tool Provider 接缝实现 Skills/Plugins 与 Lazy Metadata；OAuth/远程信任硬化进入 S13，
稳定配置与兼容性进入 S14。任何扩展来源仍不得绕过统一 Permission Pipeline。
