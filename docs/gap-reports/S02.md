- Status: Accepted — G0-G6 Passed

## 已经理解并实现

- Java Headless Runtime 是 Agent 决策权威，React/Ink 只是终端 Client；
- OpenAI-compatible 流式文本、原始 Tool Call、Finish Reason 和可信 Usage 经
  Spring AI Adapter 映射到项目协议，Reactor 类型不进入 Core；
- 一个 Assistant Turn 的多个 Tool Call 在 Runtime 中只追加一次 Assistant Message，
  并保持调用顺序与 ID；
- stdio v0 保持版本、双向序列、唯一终态、取消和 stdout 纯净边界；
- 连续 TUI Run 复用同一进程内 Session 和规范消息历史；
- 429 重试、不完整流、长度终态、Deadline、Ctrl+C、Resize、Paste、子进程崩溃和
  无孤儿进程都有确定性或本机证据；
- Run/Turn/Tool 耗时、Provider Usage 汇总和默认最小化 Telemetry 已形成独立契约。

## 已接受偏差

- 当前真实 Provider/模型只生成同回合第一个 Tool Call。Java Adapter 的双 Tool
  聚合已由本机 HTTP/SSE Contract 证明，处置见 ADR-031；
- 内部 stdio 仍为实验性 v0，不承诺稳定公共兼容；
- S02 Telemetry 没有 Metrics Backend、价格表或外部 Export Policy。
