## Reliability

- loop failures：尚未建立版本化运行期统计；离线行为以测试报告和明确 Stop Reason 为准。
- permission violations：S01 只有最小 Permission/Approval seam 和测试 Fake，未实现真实副作用权限策略，不能把该项报告为零违规。
- cancellation leaks：S01 未实现取消、超时或子进程，当前不具备可统计的取消泄漏基线。
- session corruptions：S01 只有进程内 Session 与消息不变量；没有持久化、崩溃恢复或跨进程损坏统计。

## What cc-java now does differently

1. 使用 Java 21 和框架无关 Domain，以普通同步 Java 控制流显式拥有 Agent Loop；Core 不依赖 Spring AI、Reactor、CLI、文件系统或数据库。
2. 把一个 Assistant Message 及其全部 Tool Call 视为单一规范消息，只追加一次，并要求每个 Tool Result 保留原始 Call ID。
3. 在写入 canonical history 前对整批 Tool Call 做原子预算预检；预算不足时整批不写入、不部分执行。
4. 把未知工具、非法参数和执行异常转换为可反馈给下一模型回合的结构化 Tool Result。
5. Scripted Fake Model、Fake Tool、Fake Permission 与 Fake Approval 只存在于测试源码，普通测试不需要模型 API Key。
