# S09 Hooks 差距报告

更新时间：2026-08-09

## 已完成

- 生命周期、Permission、Pre/Post Tool 与 Pre/Post Compact 已生产接入；Command Hook、严格 Trust 配置、
  provider-free 状态/批准 CLI、下一回合 transient Context Projection 达到 L2；
- Matcher 使用有界线性 glob；OBSERVE_ONLY、失败策略、稳定并发聚合、超时/取消和资源清理已验证；
- loopback HTTP Handler 具备 DNS 重检、禁止重定向与正文上限，作为本地回调达到 L1；
- S09 G0-G6 对账完成，Stage Exit Accepted。

## 仍弱于成熟参考机制

1. 远程 HTTP Hook、认证与网络隔离留到 S13；当前 loopback Handler 不是通用远程回调；
2. Prompt/Agent/Sub-Agent Hook 留到 S12/S15；Handler 不能改写 Tool Input 或重入模型；
3. 只有 CLI 的安全状态/批准入口，没有稳定 stdio/TUI Hook 活动协议；稳定协议和迁移留到 S14；
4. Hook 仍是应用层进程/网络约束，不是 OS Sandbox。

## 有意偏离

Post 事件永不阻断已经发生的副作用；additional context 不写 Canonical Transcript；项目配置变化
必须重新批准。这些偏离优先保护可恢复性、权限唯一性和会话事实。
