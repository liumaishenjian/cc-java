## 本项目独立偏离

- Permission 与 Sandbox 完全正交；默认 fail-closed，Local fallback 只能在执行前对当前 Call ID 单次显式审批。
- Linux L2 主路径明确为 Windows-hosted WSL2 Ubuntu + bwrap，Container 仅 Docker daemon/pinned image B 级的 S13 L1 optional backend；两者都不透明转换 Windows shell。
- 用 A/B/C/U 分级防止编译/Fake 证据冒充真实 OS 隔离；native Windows 只要求 B，不把 WSL2 Linux A 冒充 Windows A。
- `HOOK-10` 保持 L1；进程 backend 不能约束 JVM 内 socket。
- Managed Policy 首轮仅做不可放宽安全 baseline L1，不提前实现企业分发/迁移。
