## 未关闭 gap / blocker

1. 无 implementation Commit，不能完成 G6 commit-scoped 复验或 Stage Exit。
2. Command Hook 与 MCP stdio 已复用 `ManagedProcessLauncher` 的 fixed-argv/minimal-env seam，Sub-Agent run_command 显式继承父 backend/shell；这些宿主控制进程仍不是 OS Sandbox，MCP SDK transport 的完整 backend 隔离与远程 HTTP 强制仍是 gap。
3. native Windows 无 file/network OS sandbox；WSL2 Linux A 不替代 Windows A。macOS 无真实主机。
4. JVM 内 HTTP、MCP/Plugin remote 不受 ExecutionBackend 强制，HOOK-10 保持 L1；未来需要统一 NetworkAccessPort/egress broker。
5. bwrap 0.4.0 能力受实际 argv 限制；没有声称 seccomp、新版本 `--clearenv` 或 native Windows ACL/firewall。
6. Docker pinned digest 是本机候选验证基线；正式分发的镜像生命周期、签名/SBOM/更新属于 S14，SEC-11 保持 L0。
7. TUI 不新增专用 UI：现有启动器参数透传已能明确选择，stdio v0 保持协议兼容；稳定机器协议属于 S14。
